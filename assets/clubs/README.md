# Clublogo-assets

Deze map bevat de clublogo’s die de publieke wedstrijdmodule kan gebruiken.

De ontbrekende Eredivisie- en Eerste Divisie-logo’s zijn als SVG overgenomen van
de bijbehorende Wikimedia Commons-bestanden die via de Wikipedia-clubpagina’s
zijn gevonden. De bronpagina moet bij ieder bestand worden gecontroleerd voordat
het asset extern wordt gepubliceerd; clublogo’s kunnen naast een Commons-licentie
ook merkrechten hebben.

De operationele lookup staat centraal in `script.js`. Jong Ajax, Jong AZ, Jong
PSV en Jong FC Utrecht hergebruiken het logo van hun moederclub; er worden geen
onnodige duplicaten opgeslagen.
